## 二、问题分析

### 2.1 当前版本（v2）的核心问题

| # | 问题 | 具体表现 | 业务影响 |
|---|---|---|---|
| 1 | **关卡天花板过低** | 仅 6 关，LV6 通关约需 15–20 分钟即"毕业" | 用户生命周期极短，活动周期内无回访钩子，无法承载"程序员节"两周以上的传播节奏 |
| 2 | **难度曲线平坦** | 单步得分压力仅 40→210，且 9×9 棋盘仅出现在最后两关 | 硬核玩家快速乏味离场；新手到后期又缺乏阶梯过渡 |
| 3 | **奖励模式单一** | 通关即得固定券，无随机、无连胜、无段位概念 | "行为—奖励"回路是固定比率强化，获得一次后动机迅速衰减（游戏化设计公认的最弱强化方式） |
| 4 | **失败体验断层** | 失败即重来，无"差一点"挽回机制 | 棋差一着的玩家（约占失败玩家的 40%–60%）直接流失，无二次触发点 |
| 5 | **传播素材不足** | 通关弹窗仅一张券码截图 | 社交分享缺乏"可炫耀资产"（连胜、星级、稀有奖励），UGC 传播动力弱 |
| 6 | **成本结构粗糙** | v1 曾出现免费单品兑换码、周边直发，v2 虽下调但仍为"固定重奖" | 奖励成本与用户实际贡献（到店核销）脱钩，ROI 不可控 |

### 2.2 根因判断

v2 本质是"**通关发券**的促销工具，而非"**可留存的游戏化运营载体**"。问题不在美术与操作，而在**奖励结构**与**难度结构**两个底层设计：

- 奖励结构缺"不确定性"与"连续性"——行为心理学中，变动比率强化 + 目标梯度才是留存引擎；
- 难度结构缺"心流通道"——难度与能力不匹配时（太简单 or 太难），用户会在数分钟内离场。

## 三、奖励机制设计说明（v3 方案）

### 3.1 设计总纲

**一句话：用"12 关心流曲线"拉长生命周期，用"行为心理学奖励栈"提升回访与分享，用"加权概率惊喜盒"替代固定重奖以控制成本。**

### 3.2 机制一：可变比率奖励——麦乐惊喜盒

| 参数 | 设计值 | 说明 |
|---|---|---|
| 常规通关掉率 | 45% | 每关固定概率掉落 1 个惊喜盒 |
| **每日首通掉率** | **70%** | 当日首次通关掉率提升，制造"今天再来一局"的回访锚点 |
| 奖池五档（加权） | 普通 50 / 精良 25 / 史诗 15 / 传说 7 / 限定 3 | 权重合计 100，限定档约 3% 的稀缺性制造话题 |
| 开奖动效 | 老虎机式滚动 0.9 秒后揭晓 | 延长期待时长，强化悬念体验 |

**行为心理学原理（可变比率强化，Variable-Ratio Schedule）**
斯金纳箱实验证明：**不确定的奖励比确定的奖励更能维持行为**。固定比率（每按 10 次给食）会让鸽子在奖励后暂停；而变动比率让鸽子持续高频按键。这正是盲盒与抽卡商业模型的心理学基础——45% 而非 100% 的掉率，使"再通一关"的动机不因上次没中而熄灭，反而因"下次可能中"而增强。

### 3.3 机制二：损失厌恶——连胜计数

| 参数 | 设计值 |
|---|---|
| 连胜计数 | 连续通关累计 🔥 N 连胜，失败清零并在弹窗明示"连胜已中断" |
| 连胜奖励 | 3 连胜 +1 盒 / 5 连胜 +2 盒 / 8 连胜 +3 盒 |

**行为心理学原理（损失厌恶，Loss Aversion）**
卡尼曼前景理论：**等量损失的心理痛苦约为等量收益快感的 2–2.5 倍**。"连胜"将抽象进度转化为用户**已经拥有**的资产，失败不仅是"没得到"，而是"失去已持有的 5 连胜"——后者驱动的复访意愿显著更强。弹窗明示"连胜已中断"即是刻意放大损失感知。

### 3.4 机制三：近失效应——每日续命券

| 参数 | 设计值 |
|---|---|
| 触发条件 | 失败时得分 ≥ 目标分 60%（如目标 3000，得 1800 分） |
| 效果 | +3 步，立即继续当前关卡（保留棋盘与分数） |
| 限制 | 每日 1 次，防成本失控同时制造稀缺 |

**行为心理学原理（近失效应，Near-Miss Effect）**
老虎机研究（Clark et al., 2009）表明：**"差一点就赢"会激活与真实获胜相近的奖赏回路**，并显著提升"再试一次"的行为频率。棋差 200 分就放弃的玩家，是游戏中最可惜的流失人群——续命券把"失败"改写为"差点成功"，配合每日 1 次的限制，既挽回近失玩家又控制券成本。

### 3.5 机制四：峰终定律——章节宝箱

| 节点 | 配置 |
|---|---|
| LV4 / LV8 / LV12 章节宝箱关 | 保底 2 个惊喜盒 |
| LV12 终极宝箱（BOSS 关） | 保底 3 个惊喜盒 |

**行为心理学原理（峰终定律，Peak-End Rule）**
卡尼曼：人对一段体验的记忆 ≈ **峰值时刻 + 结束时刻**的评价，与过程平均体验几乎无关。章节宝箱刻意放在每章最后一关，制造"章节高光收尾"——用户回忆"第二章很爽"而非"第二章中间有几关挺难"，直接改善活动整体口碑与复购记忆。

### 3.6 机制五：目标梯度——星级与章节进度

| 参数 | 设计值 |
|---|---|
| 星级 | 按剩余步数评 1–3 星（剩 ≥6 步 3 星 / ≥3 步 2 星 / 其余 1 星） |
| 章节进度 | 关卡地图显示"本章 ⭐ x/12"，进度可视化 |

**行为心理学原理（目标梯度效应，Goal Gradient）**
胡尔与克莱默经典实验：**越接近可见目标，行为速率越快**。未充值的咖啡卡（差 2 格满）比新卡的消费频率更高。章节星级进度把"还要打几关"变成"再拿 3 颗星就满章"，利用接近感驱动用户主动补星重刷。

### 3.7 机制六：心流理论——12 关 / 3 章难度曲线

| 章节 | 关卡 | 单步得分压力（目标分 ÷ 步数） | 定位 |
|---|---|---|---|
| 第一章 · 麦满分早晨 | LV1–4 | 38.9 → 86.4 | 成长期：小棋盘建立掌控感，LV3 起引入冰块教学 |
| 第二章 · 麦乐鸡正午 | LV5–8 | 109.1 → 200.0 | 挑战期：压力陡增，种类 8→9、冰量 6→12 |
| 第三章 · 麦麦省之夜 | LV9–12 | 209.1 → 283.3 | 硬核期：10 种食物 + 9×9 + 冰量 14→18，LV12 BOSS 双层厚冰收尾 |

**行为心理学原理（心流理论，Flow）**
契克森米哈伊：当**挑战难度与个人能力动态匹配**时，人进入沉浸状态（时间感消失、自我意识减弱）——这是留存的终极状态。v3 的核心工程量在于：**单步压力全程单调不降、逐关平滑抬升，无断崖式跳跃**（已用自动化测试断言保证）。太简单 → 无聊离场；太难 → 焦虑弃坑；12 关的阶梯让不同水平的用户各自找到自己的心流区间。

### 3.8 奖励成本控制（相较 v1）

| 项目 | v1 | v3 | 变化 |
|---|---|---|---|
| 最高单关奖励 | 免费单品兑换码 + 限定周边直发 | 满 30 减 5 元券 | 全面券化 |
| 券有效期 | 长有效期 | 3 天 | 缩短核销窗口、加速回流到店 |
| 发放量 | 每关必得 | 惊喜盒 45%/70% 概率 + 保底兜底 | 期望成本可精确预估 |
| 单用户期望盒数（12 关全通 + 每日首通） | — | 约 8–11 盒 | 盒内券面额已全线低于 v1，**总成本可控且低于 v1** |

## 四、营销推广价值

### 4.1 对官方的四大价值

| 价值维度 | 具体说明 |
|---|---|
| **传播周期拉长** | 6 关 → 12 关，单用户完整体验从约 15 分钟拉长至 3–5 天（含每日首通钩子），恰好覆盖程序员节活动窗口，把"一次性互动"变成"多日campaign" |
| **UGC 素材生产机** | 连胜截图（🔥 N 连胜）、稀有奖励揭晓（传说/限定档）、满星章节地图——三类天然"可炫耀资产"，每一张都是带麦当劳品牌元素的社交货币 |
| **到店核销引擎** | 全部奖励为 3 天有效期满减/折扣券，游戏行为直接导向门店核销；续命券与连胜机制显著提升"再玩一局"频率，同步提升券领取量 |
| **品牌年轻化叙事** | "程序员节 + 行为心理学 + 游戏化运营"本身就是面向开发者与年轻白领的科技话题，利于官方 PR 二次传播（大赛作品故事线） |

### 4.2 传播链路设计

```
扫码/链接进入（无登录门槛）
   ↓
第一章心流入门（LV1-4）→ 通关得券 → 截屏分享（基础素材）
   ↓
第二章连胜开启 → 🔥连胜截图分享（社交货币①）
   ↓
每日首通 70% 掉率 → 回访锚点（连续 3 天打开）
   ↓
章节宝箱 LV4/8/12 → 峰值时刻晒图（社交货币②）
   ↓
传说/限定档开奖 → 稀有奖励晒图（社交货币③，3% 概率制造"欧皇"话题）
   ↓
3 天有效期 → 到店核销 → 门店场景二次曝光
```

### 4.3 可叠加的官方运营动作（建议）

1. **官方话题运营**：活动期发起 #麦麦省之王# 话题，晒 LV12 通关截图抽限定周边（把游戏内 3% 的"限定档抽奖资格"接到官方话题上）；
2. **门店物料联动**：收银台台卡印"扫码消消乐，满 15 减 2"，把等餐时间转化为游戏时间；
3. **麦麦送场景延伸**：通关弹窗增加"顺手点一单"入口，衔接 `mcd-mcp` 的 `query-nearby-stores` → `query-meals` → `calculate-price` 链路，游戏流量直接转外卖订单。

## 五、预期用户留存与付费转化提升（预估）

> 以下为基于同类游戏化 H5 活动行业基准的**预估区间**（非承诺值），实际以 A/B 测试校准。

| 指标 | v2 基线（估） | v3 目标（估） | 提升逻辑 |
|---|---|---|---|
| 人均游戏局数 | 约 6–9 局（打通即走） | **18–30 局** | 12 关 + 每日首通钩子 + 补星重刷 |
| 次日回访率 | 约 15%–20% | **35%–45%** | 每日首通 70% 掉率 + 连胜不断裂激励 + 续命券每日刷新 |
| 7 日留存率 | 约 8%–12% | **20%–28%** | 心流阶梯 + 章节宝箱节奏 + 连胜资产 |
| 券领取率（UV→领券） | 约 50%–60% | **70%–80%** | 惊喜盒把"固定领券"升级为"开奖领券"，领取动作本身游戏化 |
| **券核销率（领券→到店）** | 约 20%–25% | **30%–38%** | 3 天有效期 + 惊喜盒多券组合（提高至少一张被用掉的概率）+ 续命券引导"趁热到店" |
| 单用户活动成本 | 中（固定发券） | **中低（加权概率 + 券面额下调）** | 期望成本 = Σ(档位概率 × 面额)，可精确预算 |
| UGC 分享率 | 约 3%–5% | **10%–15%** | 连胜/稀有奖励/满星三类炫耀资产 |

**核心假设**：以上预估成立的前提是官方同意"每日首通 70% 掉率"与"连胜奖励盒"两项配置——它们是回访引擎，也是本方案与 v2 的本质差异。

## 六、合规事项（须官方确认）

| # | 事项 | 要求 |
|---|---|---|
| 1 | **概率公示** | 惊喜盒为随机奖励，弹窗已内置概率公示文案（普通50%/精良25%/史诗15%/传说7%/限定3%），须与官方最终配置一致，符合《网络游戏管理暂行办法》及盲盒经营合规要求 |
| 2 | **未成年人保护** | 随机奖励机制不得向未成年人提供付费抽取；本方案奖励全部免费获取（游戏行为获得），无付费入口，但仍建议官方按活动规则补充适龄提示 |
| 3 | **商标与品牌** | 麦当劳、McDonald's、巨无霸、麦乐鸡、麦麦省等商标使用须经官方授权，演示版仅作大赛展示 |

| 6 | **活动备案** | 如惊喜盒被认定为抽奖性质运营活动，须由官方完成相应活动备案 |

## 七、分阶段落地执行计划（**待官方正式同意后**启动）

> **再次声明：以下全部阶段均在获得麦当劳官方正式同意（书面确认）后启动；未获同意前，线上维持 v2 不变。**

### Phase 0 · 官方评审（第 1–2 周）
- 提交本建议书至官方活动组委会 / 市场部评审；
- 确认点：奖池档位与面额、每日首通掉率、连胜奖励梯度、续命券规则、周边抽奖可行性；
- **出口条件**：获得官方书面同意 + 法务合规确认。

### Phase 1 · 灰度验证（第 3–4 周，10% 流量）
- 上线 v3 机制（12 关 / 惊喜盒 / 连胜 / 续命券），保留一键回退 v2 开关；
- 灰度埋点：各关通过率、盒掉落/开启数、连胜分布、续命券使用率、券核销率；
- **出口条件**：灰度数据不低于预估区间下限的 80%，无客诉异常。

### Phase 2 · 全量上线（第 5–6 周）
- 全量开放 v3；同步开启官方话题 #麦麦省之王# 与门店台卡物料；
- 每周监控：回访率、核销率、单用户成本，必要时微调券面额（不动概率结构）。

### Phase 3 · 链路深化（第 7–8 周，可选）
- 接入 `mcd-mcp` 真实券发放（`auto-bind-coupons`），替换演示占位码；
- 麦麦送场景加"顺手点一单"入口，衔接完整下单链路；
- 依据数据决定是否增设"第二季"关卡（复用同一心流框架）。

### 风险与回退
| 风险 | 应对 |
|---|---|
| 官方不同意概率型奖励 | 降级方案：惊喜盒改为"连胜 3 关必得 1 盒"的固定比率版，保留连胜与心流曲线 |
| 券成本超预算 | 下调史诗/传说档权重（15/7 → 10/5），普通档权重补足；或缩短券有效期至 2 天 |
| 未成年人抽奖合规风险 | 切换为"登录用户实名校验后参与"或改为非随机保底奖励 |
| 用户反馈 LV12 过难 | 微调 BOSS 关步数 24→26 或冰量 10→8，保持"难但可过"的心流上沿 |

## 八、总结

v3 不是"更难的游戏"，而是"**更懂人的奖励系统**"：

- **可变比率奖励**让"再玩一局"停不下来；
- **损失厌恶**让连胜不忍中断；
- **近失效应**把失败改写成"差点成功"；
- **峰终定律**让每章都留下高光记忆；
- **心流曲线**让 12 关各自找到匹配的用户；
- **目标梯度**让满星与连胜成为可追逐的可见资产。

对官方而言，这套系统把一次性的程序员节互动，升级为**可留存、可分享、可核销、成本可控**的战役级游戏化运营载体。

**以上方案待麦当劳官方正式同意后，按第七节分阶段计划执行。**
