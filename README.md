> **2026 麦当劳程序员创意开发大赛**参赛作品 —— 基于麦当劳 MCP（`mcd-mcp`）能力的游戏化互动项目。
> 一款零门槛的网页消消乐：玩家在限定步数内消除麦麦美食、击碎冰块，通关即得「麦麦省」优惠券，还有概率掉落五档加权的**麦乐惊喜盒**。

## 1. 项目介绍

「麦麦消消乐」把麦当劳的优惠券权益装进了一个 1–2 分钟一局的轻量三消游戏里：

- **12 关 / 3 章节心流曲线**：从 6×6 新手关到 9×9 BOSS 关（双层厚冰），单步得分压力平滑上升（38.9 → 283.3），新手到硬核玩家各自找到心流区间；
- **六大行为心理学奖励机制**：可变比率奖励（惊喜盒）、损失厌恶（连胜计数）、近失效应（每日续命券）、峰终定律（章节宝箱）、目标梯度（星级进度）、心流理论（三章难度阶梯）；
- **优惠券直接导向到店核销**：通关奖励全部为满减/折扣券，带使用条件与 3 天有效期，游戏流量转化为门店订单；
- **MCP 生产链路已设计**：演示版用占位券码展示 UX，生产版通过麦当劳 MCP 的 `auto-bind-coupons` 等工具发放真实「麦麦省」券（见 [MCP_INTEGRATION.md](MCP_INTEGRATION.md)）。

技术形态：**纯 HTML/CSS/JS 单文件**（`index.html`，约 36KB），无任何构建依赖，可直接静态部署（EdgeOne Pages / GitHub Pages / 任意静态服务器），也可二次改造为公众号 H5 或微信小程序 WAP 版。

## 4. 玩法规则速览

- 横向/纵向连成 **3 个及以上**即消除，Combo 倍率计分（`消除数 × 10 × combo`）；
- 通关条件：限定步数内**同时**达成目标分数 **且** 击碎全部冰块；
- 星级：剩余 ≥6 步 3 星 / ≥3 步 2 星 / 其余 1 星；
- 死局保护：无可消步骤时自动重排（冰块保留）；闲置 6 秒高亮提示。

## 6. 奖励系统与行为心理学原理

| 机制 | 游戏实现 | 心理学原理 |
|---|---|---|
| 可变比率奖励 | 惊喜盒掉率 45%（每日首通 70%），五档加权奖池：普通50/精良25/史诗15/传说7/限定3 | 变动比率强化是维持行为最持久的强化方式，不确定性让"再开一局"的动机不衰减 |
| 损失厌恶 | 🔥连胜计数失败清零，弹窗明示"连胜已中断"；3/5/8 连胜额外惊喜盒 | 损失的心理权重约为等量收益的 2 倍，用户为避免"失去连胜"而继续游戏 |
| 近失效应 | 得分 ≥ 目标 60% 且当日未用 → 续命券 +3 步（每日 1 次） | "差一点就赢"激活与真实获胜相近的奖赏回路，激发"再试一次" |
| 峰终定律 | LV4/8/12 章节宝箱（保底 2 盒）+ LV12 终极宝箱（保底 3 盒） | 体验记忆由峰值与终点决定，章节高光收尾定义整章评价 |
| 目标梯度 | 章节 ⭐x/12 进度 + 关卡地图可视化 | 越接近可见目标行为速率越快 |
| 心流理论 | 三章难度阶梯，单步压力全程平滑不降（测试断言保证） | 难度与能力动态匹配产生沉浸，是留存的核心 |

惊喜盒奖池：满 15 减 2 元券（50）/ 麦乐鸡 5 块 9.5 折券（25）/ 巨无霸 8 折券（15）/ 满 30 减 5 元券（7）/ 程序员节限定周边抽奖资格（3，待官方配置）。弹窗内置概率公示。
